# فرم ثبت‌نام با اعتبارسنجی زنده
 
فرم ثبت‌نامی با HTML، CSS و JavaScript خالص که ایمیل، رمز عبور و تکرار رمز را به‌صورت زنده (بدون رفرش صفحه) اعتبارسنجی می‌کند.
 

 
## دمو
 
[لینک نسخه‌ی آنلاین (GitHub Pages) رو اینجا بذار]
 
## امکانات
 
- اعتبارسنجی زنده‌ی ایمیل با `checkValidity()` مرورگر
- اعتبارسنجی زنده‌ی رمز عبور (حداقل ۶ کاراکتر)
- بررسی زنده‌ی تطابق تکرار رمز با رمز اصلی
- نمایش/مخفی کردن رمز عبور با کلیک روی آیکون چشم
- ارسال فرم بدون رفرش صفحه (`preventDefault`)
- نمایش پیام موفقیت در خود صفحه
## تکنولوژی‌ها
 
- HTML5
- CSS3
- JavaScript (Vanilla)
- Font Awesome 
## شفافیت استفاده از AI
 
بخش‌هایی از این پروژه با کمک Claude (دستیار هوش مصنوعی Anthropic) ساخته شده‌اند:
 
- **آموزش مفهومی:** مفاهیم پایه‌ی جاوااسکریپت (تابع، رویداد، آرایه، آبجکت) با راهنمایی Claude و به‌صورت گام‌به‌گام یاد گرفته شد؛ کدها را خودم می‌نوشتم و Claude فقط راهنمایی و رفع اشکال می‌کرد.
- **بازسازی کد (Refactor):** بعد از دریافت بازخورد منتور، اصلاحاتی مثل تبدیل منطق تکراری اعتبارسنجی به تابع‌های مجزا (`isEmailValid`, `isPasswordValid`, `doPasswordsMatch`) و استفاده از `checkValidity()` به‌جای `includes()` با کمک Claude انجام شد. من هر تغییر را می‌فهمیدم، تست می‌کردم و خودم اعمال می‌کردم.
- **متن README:** ساختار این فایل با کمک Claude نوشته شد.
پرامپت‌های اصلی استفاده‌شده حول محور «آموزش مفهوم X» و «چرا این ایراد پیش اومده و چطور درستش کنم» بودند، نه تولید مستقیم کد آماده برای کپی بدون فهم.
