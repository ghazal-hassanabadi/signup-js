# فرم ثبت‌نام با اعتبارسنجی 
 
یه فرم ثبت‌نام ساده که با HTML، CSS و JavaScript  اعتبارسنجی فیلدها به‌صورت زنده و بدون نیاز به رفرش صفحه انجام می‌شه.
 
## امکانات
 
- بررسی زنده‌ی ایمیل (باید شامل `@` و `.com` باشه)
- بررسی زنده‌ی رمز عبور (حداقل ۶ کاراکتر)
- بررسی زنده‌ی تطابق تکرار رمز عبور با رمز اصلی
- نمایش/مخفی کردن رمز عبور با کلیک روی آیکون چشم
- ارسال فرم بدون رفرش صفحه (Prevent Default)
- طراحی رابط کاربری با تم تیره
## تکنولوژی‌ها
 
- HTML5
- CSS3
- JavaScript (Vanilla)
- Font Awesome (برای آیکون‌ها)
